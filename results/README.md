# sWARm Results Directory

This directory contains output files generated by the sWARm analysis system.

## Directory Structure

### `/results/` - Main Results
- **`future_projections_YYYY.csv`** - Multi-year player projection results from sWARm_FutureProjections.ipynb
- **`validation_report.csv`** - Model validation cross-fold performance reports

### `/results/issues/` - Diagnostic and Issue Logs
- **`dropped_players_log.txt`** - Log of players dropped during data processing due to incomplete data

## File Descriptions

### Future Projections (`future_projections_YYYY.csv`)
Contains 1-3 year projections for eligible players including:
- Player demographics (Name, Age, Position)
- Current season performance (Current_WAR, Current_WARP)
- Future projections (projected_WAR_year_1, projected_WAR_year_2, projected_WAR_year_3)
- Equivalent WARP projections
- Constraint validation results (zero-sum WAR totaling 1000)

### Validation Reports (`validation_report.csv`)
Contains model performance metrics from temporal cross-validation:
- Longitudinal model performance (R², RMSE, MAE)
- Survival model performance (Concordance Index)
- Performance across validation folds
- Model assessment summaries

### Dropped Players Log (`issues/dropped_players_log.txt`)
Diagnostic log showing:
- Players excluded from analysis due to incomplete data
- Reasons for exclusion (missing features, insufficient playing time)
- Data quality issues for debugging

## Usage Notes

- **Future projections** are generated annually and saved with the target season year
- **Validation reports** are generated during model training and validation phases
- **Issue logs** help identify data quality problems and player filtering decisions
- All files use timestamp-based naming when applicable for version tracking

## Integration with sWARm System

These results are generated by:
- `sWARm_FutureProjections.ipynb` → future projections and validation reports
- Future season modules (`integration.py`, `data_integration.py`) → issue logs
- Model validation pipeline → validation reports

Results can be analyzed, visualized, or exported for further baseball analytics research.
